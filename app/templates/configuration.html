DocuSign e-Signature

Connect to DocuSign so you can send documents directly to customers for electronic signature from the Document Editor.

How it works: You click Send for Signature on a saved document → Ambifo converts it to PDF → uploads to DocuSign → DocuSign emails the customer automatically → customer signs in their browser (no account needed) → you see the signed status update here.

Setup steps: 1. In DocuSign Admin → Apps & Keys → create an Integration Key.
2. Add an RSA keypair, copy the private key here.
3. Grant consent: visit https://account-d.docusign.com/oauth/auth?response_type=code&scope=signature%20impersonation&client_id=YOUR_KEY&redirect_uri=https://www.docusign.com
4. Use Sandbox URL https://account-d.docusign.com for testing, https://account.docusign.com for production.
